# Ek Gıda Planı

Bebekler için 30 günlük ek gıda başlangıç planı, kaynaklı araştırma rehberi ve takip uygulaması. Tek dosyalık, mobil uyumlu HTML.

- 30 günlük plan (6. ay başlangıcı), gıda listesi, denendi / tepki takibi
- Rehber: WHO 2023, ESPGHAN, AAP, T.C. Sağlık Bakanlığı ve 2025 çalışmalarından özet, kaynak linkleriyle
- Güvenlik kuralları, boğulma riski, acil durum bilgisi
- İlerleme tarayıcıda (localStorage) saklanır

Kullanım: `index.html` dosyasını tarayıcıda aç. GitHub Pages: Settings > Pages > Branch: main.

> Genel bir rehberdir; bebeğin durumuna göre çocuk doktoruna danışın.
